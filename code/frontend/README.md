# Frontend

本地 Tome 网页工作室，使用原生 HTML、CSS 和 JavaScript，无需安装前端依赖。

从仓库根目录运行 `code\backend\run-web.cmd`，打开 http://127.0.0.1:8765。

- 创建作品、设置故事构想和目标篇幅。
- 书架右侧菜单支持置顶、取消置顶和删除；删除先移入作品目录的 `.trash/`。书架底部左侧的「废案箱」显示数量，可查看并恢复所有已删除作品；生成中的作品不能删除。
- 废案箱支持单部作品「彻底删除」；需要输入完整作品名称并二次确认，删除正文、文风和存档后不可恢复。
- 生成下一章，后台执行新版事件先行、三层记忆流程。
- 阅读章节、查看版本化事实记忆、导出 Markdown。
- 事实记忆按人物或章节生成简短主题标题，通过下拉框选择后查看；正文来源按需展开。
- 在新建作品时或作品页设置文风要求和参考片段，按作品保存；生成前自动保存当前修改，从下一章起生效。
- 先生成第一章并人工确认，再勾选自动续写；自动填写剩余章节数，可手动修改。
- 每次生成前显示预计输入/输出 token 和人民币费用，点击「继续生成」才调用模型；取消不会启动任务。

作品使用仓库默认的 `service.generate`。旧版已写章节仅供阅读和导出，防止新引擎覆盖历史正文。

文风要求最多 2,000 字，参考片段最多 6,000 字。设定独立存放于作品目录的 `writing-style.json`，不会改变原检查点的计划哈希。每次正文生成、格式修复和篇幅调整均向 writer 传入同一份文风设定；参考片段不会作为规划或记忆输入。生成期间不能修改文风，已写章节不会重写。清空两项并保存即可恢复默认。

用量预估优先参考上次成功请求的实际用量，结合目标篇幅、上下文及多阶段调用作粗估，误差可能较大，不是承诺或扣费上限。单价由 `official_pricing.py` 从 [DeepSeek 官方定价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 自动读取，按北京时间、周末和 2026 年法定节假日判断峰谷，六小时刷新一次；读取失败时沿用已核验价表，界面显示来源与核验日期。费用使用输入未命中缓存价格，额外展示高峰价参考，无需手动填写。旧模型名 `deepseek-chat` / `deepseek-reasoner` 仅采用 Flash 参考价并明确标注，不自动更改实际调用模型；未识别模型不会套用免费价格。以后年度日历尚未更新时，工作日峰时保守按高峰估算并提示。

批量生成逐章保存检查点并显示已完成数量；中断、失败时已保存章节仍可阅读和导出。确认前若已切换峰谷时段或官价变化，需要重新预估并确认。

同源 API 由 `code/backend/inf_backend/web.py` 提供，服务仅监听 `127.0.0.1`。真实生成需要在 `code/backend/.env` 中配置 DeepSeek 密钥；密钥不会发送到浏览器。
