# Tome Agent 用户测试

## 测试目的

验证用户能否从故事构想完成作品创建、生成、保存、续写及导出。以下为测试方案；执行结果应由实际测试人员记录，不能将未执行的步骤标为通过。

## 准备

- 使用独立的测试作品，确认模型服务可用；真实模型调用可能产生费用。
- 测试前记录应用版本、测试日期、测试环境和测试人员；不要在测试记录中填写 API Key 或密码。
- 首次使用前参考 [使用说明](../docs/software/USER_GUIDE.md)启动工作室。

## 场景与预期

| 编号 | 用户操作 | 预期结果 |
| --- | --- | --- |
| UAT-01 | 打开工作室，进入作品书架 | 页面可用，能够进入创建作品界面。 |
| UAT-02 | 填写故事构想、章节数、字数和可选文风，创建作品 | 作品创建成功并可打开；输入提示清楚可见。 |
| UAT-03 | 查看生成预估并确认生成第一章 | 生成任务启动；完成后能够阅读第一章。 |
| UAT-04 | 刷新页面并重新打开作品 | 已保存的章节仍可阅读。 |
| UAT-05 | 确认首章后生成下一章 | 第二章可保存，已有章节仍可读取。 |
| UAT-06 | 导出作品 | 导出文件包含已保存的章节内容。 |
| UAT-07 | 取消文件选择或生成确认 | 返回当前界面，保留已输入的内容。 |
