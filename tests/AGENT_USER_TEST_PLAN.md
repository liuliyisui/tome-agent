## 准备与约定

1. 使用测试用作品与测试账号，提前记录当前模型、程序版本和测试时间。准备一部至少有一章正文及事实记忆的测试作品；需要生成章节时先查看预估，由测试者自行确认余额和费用。
2. 全程使用虚构人物、虚构情节与测试用假号码，不输入真实身份证、手机号、密钥或私人作品。不要把 API Key、完整请求、私人正文或个人信息放入截图和报告。
3. 记录实际操作路径、现象、时间、截图编号和版本；多项子问题分别记录，不能只回答其中一项。对不提供聊天、联网检索或引用的功能，写明实际无法操作及影响，不把“不适用”当成通过。
4. 测试者亲自操作并填写：**通过 / 部分通过 / 不通过 / 未覆盖**。未执行、无法触发或无足够证据的内容标记“未覆盖”，并说明原因；有步骤失败则依据实际影响判定。以下为建议判定依据，最终以真实观察和课堂标准为准。
5. 优先在隔离测试环境模拟断网、错误密钥、超时及长等待；真实模型请求可能产生费用，连接测试也可能产生费用。涉及不当内容的测试使用无详细操作细节的安全样例；涉及隐私的测试仅用明显虚构数据。
