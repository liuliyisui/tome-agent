# Tome · AI 交互原型

这是利用 AI 辅助生成并整理的可交互原型，作为 `docs/software/prototype` 的展示材料。界面沿用本项目的 Vue 3 工作室，以浏览器中的模拟数据展示主要创作流程。正式产品中的模型生成、服务端存储和接口不在这个原型内执行。

## 打开方式

直接用现代 Edge、Chrome 或 Firefox 打开本目录的 [index.html](index.html)。无需 Python、Node.js、网络连接或 API Key。所有脚本、样式与 Vue 运行时均包含在目录内；提交或复制时请保留整个目录。

若通过静态网站展示，将本目录完整发布到任意静态服务即可；支持放在子路径中。需要本地 HTTP 预览时，可以在仓库根目录运行 `python -m http.server 8768 --bind 127.0.0.1 --directory docs/software/prototype`，再访问 `http://127.0.0.1:8768/`。

## 推荐演示顺序

1. 首页：展示独立欢迎页，点击右上角「我的作品」进入书架。
2. 作品页：打开「雨夜来信」，切换章节，查看段首缩进；在事实记忆中选择主题，展开正文依据。
3. 文风设定：修改文风要求和参考片段，点击保存；切换页面再回来，设定保留。
4. 续写确认：确认第一章适合续写，调整章节数，点击预估按钮；费用框展示输入、输出 token 和样例费用。取消不会生成，继续则模拟逐章完成并更新正文及记忆。
5. 创建作品：返回首页，点击「创建新的作品」，填写名称、故事构想和目标篇幅，创建后先生成第一章，再体验续写流程。
6. 管理作品：在书架菜单中置顶或删除作品；在侧栏底部「废案箱」恢复作品，或输入完整名称后彻底删除示例作品。
7. 导出：在作品页点击「导出作品」，下载包含段首全角空格的 Markdown 文件。

## 数据和边界

- 初始示例为原创虚构的「雨夜来信」和「星海拾光」，不含真实作品、用户信息或密钥。
- 增删改操作仅保存在当前浏览器的专用 localStorage 键 `tome-interactive-prototype-v1` 中。浏览器禁止存储时仍可体验当前页面，刷新后可能重置。
- 页面底部始终提示「交互原型」。点击「重置示例」并确认可恢复初始状态。
- 生成使用固定示例正文和延迟进度，不调用任何 AI 接口。刷新时已完成的章节保留，未完成的模拟任务中止，可重新提交。
- 费用为固定示例值，明确标注非实时官价，不产生费用，不能作为实际模型报价依据。官方定价链接仅供自行访问。
- 原型不会访问正式产品 API；运行原型无需启动工作室后端，也不会更改 `code/backend/data` 中的真实存档。

## 文件说明

`index.html` 是入口；`app.js`、`vue-components.js` 和 `style.css` 是工作室界面的展示快照；`prototype.js` 提供独立模拟数据、模拟请求、生成进度和本地导出；`vue.runtime.global.prod.js` 是本地 Vue 3.5.44 运行时，其 MIT 许可在 `vue.LICENSE.txt` 中。

原型只用于交互展示。正式产品仍从 `code/frontend` 和 Python 后端启动，没有增加离线演示入口。修改正式界面后，需同步原型快照并保留相对路径和模拟适配层。
