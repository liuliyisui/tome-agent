# 测试流程与顺序（45 分钟，用操作路径留证）

> 不截图，证据统一写成**操作路径 + 一句话现象**。课程原表允许两种留痕方式（"截图编号或操作路径"），这里全程用后者。
> 全程同一个浏览器窗口（1440×900），中途不刷新页面；总时长 45 分钟。

## 先统一路径写法（1 分钟，决定后面所有格子好不好读）

**模板**：`页面/区域 → 控件 → 动作：现象`

- 用 `→` 连接，最多 5 段，从最外层页面名开始，到具体控件停下。
- 控件名用界面上的**原文**（加中文引号），不要自己起名字。
- 冒号后写现象：带数值、原文文案、发生顺序。
- 一条路径必须能让别人**照着点出同样结果**，否则等于没证据。

| 不合格 | 合格 |
|---|---|
| 页面很乱 | `作品页 → 顶部横幅：占屏约 1/3，含「新手教程」按钮` |
| 间距不统一 | `作品页 → F12 Elements → 选两张卡片 → Computed：border-radius 8px / 10px / 12px` |
| 没有空状态 | `对话页 → 清空对话后 → 主区：空白，无引导文案` |
| 错误提示很差 | `对话页 → 断网 → 点「发送」：输入框被清空，无文字提示` |

**记录区**（第七节）每行填：记录号、时间、操作路径、看到的现象；「截图编号」栏统一写 `—`。

## 阶段 0：准备（3 分钟）

1. `F12` 打开 DevTools → 右上 `⋮` → **停靠侧 → 取消停靠到单独窗口**（停靠右侧会把页面压窄，V3 量的值全错）。
2. Console 里跑一次，把结果抄进报告头部的「浏览器 / 设备」栏：

```js
`${navigator.userAgent} | ${innerWidth}×${innerHeight} | dpr ${devicePixelRatio}`
```

3. 确认系统缩放 100%、窗口 1440×900、没开设备模拟（`Ctrl+Shift+M` 不要按）。
4. 手机秒表按好（或 Console 里 `t0 = performance.now()`），H7 要用。

## 阶段 1：H7 首次体验（5 分钟）

1. 按秒表，从打开 URL 开始，**不要先随便点**。
2. 记到第一个答案的**步数、点击数**；若需注册/填 Key，每步都算进去。
3. 第二次提问试 Enter 发送、Shift+Enter 换行。
4. 打开设置，看有没有默认值。

留证示例：`打开首页 → 输入「你好」→ 点「发送」：2 步 2 次点击；无需注册；设置中模型名已预填`

## 阶段 2：静态观察（6 分钟，不动手）

- **H6**：首屏有没有示例问题、预设选项、设置说明。
- **H8**：列出主界面元素，逐个判断是否服务"提问并拿到答案"。
- **H2**：扫首屏、设置页、按钮提示，把技术词原文抄下来（错误提示留到阶段 4、6）。

留证示例：`首页 → 输入框下方：无示例问题，仅 placeholder「输入你的问题」`

## 阶段 3：V3、V4（9 分钟，DevTools）

1. 保持 1440 宽，**先别缩窗口**（响应式会改间距）。
2. 取 5 组元素记值：主次按钮、两张同层卡片、两个弹窗、列表项、输入框与气泡。
3. 图标清单：发送、重试、清空、设置、箭头；抽 2 个 `<svg>` 看 `stroke-width`。
4. 数插画张数、看是否 emoji 混用。

留证示例：`作品页 → Elements → 选「主按钮」与「次按钮」→ Computed：padding 12px 20px / 10px 16px`

## 阶段 4：状态与校验（H1 前半、H5）（8 分钟）

由轻到重，避免早早就把会话弄脏：

1. 空输入点发送。
2. 粘贴 1 万字发送（看上限提示/截断）。
3. 发"请详细分 5 点回答" → 观察加载态与阶段提示；**等答案的时间切去 DevTools 补完 V3/V4**。
4. 发违规内容触发拦截（放这里，可能触发风控）。
5. 点清空对话，看有无二次确认（先记路径再清）。

## 阶段 5：控制与一致性（H3、H4）（8 分钟）

1. 六项逐个点：清空、编辑/撤回、重新生成、中途停止、删除历史、恢复默认。
2. 顺手对照 H4：发送（输入区按钮 / 回车提示 / 快捷键说明）、重试（消息下方 / 错误提示）、清空（设置 / 更多菜单）。
3. 删除历史用废弃会话，别删主会话。

留证示例：`对话页 → 悬停消息：仅出现「复制」；生成中无「停止」按钮`

## 阶段 6：断网（H9）（5 分钟，最后做）

1. 输入框里先写一行字。
2. DevTools → Network → Throttling → **Offline**（或断 Wi-Fi）。
3. 点发送 → 记错误原文、输入是否被清空。
4. 点重试 → 是否需要重新输入；连错两次 → 有无备选。
5. 改回 `No throttling`，确认会话还能继续。

留证示例：`对话页 → Network 切 Offline → 点「发送」：0.5 秒后输入框清空，页面无任何提示`

## 45 分钟时间表

| 时间 | 阶段 | 只做这些 |
|---|---|---|
| 0–3 | 准备 | 取消停靠 DevTools、记环境、开秒表 |
| 3–8 | H7 + 首屏观察 | 计时数步数；顺带看 H6 示例、H8 无关元素、H2 首屏技术词 |
| 8–14 | V3 | 量 5 组元素，边量边记路径 |
| 14–17 | V4 | 抽 4 个图标看线宽尺寸，数插画 |
| 17–25 | H1 + H5 | 空输入 → 1 万字 → 长问题（等待时补 V3/V4）→ 违规 → 清空确认 |
| 25–33 | H3 + H4 | 六项逐个点，顺手对照三处图标文案 |
| 33–38 | H9 | 断网发送、看原文、重试、连错两次、恢复 |
| 38–42 | 补记录 | 第七节逐条登记路径与现象 |
| 42–45 | 交付 | 11 条发给协作方 / 粘表 |

## 顺序为什么这么排

| 排序 | 理由 |
|---|---|
| H7 最先 | 学习效应：第二遍一定比第一遍点得少 |
| 静态先于交互 | 首屏与文案不受后续操作影响 |
| V3/V4 在 1440 宽做 | 缩窗触发响应式断点，间距和圆角会变 |
| 空输入/超长 → 长问题 → 违规 | 由轻到重；违规可能触发风控，放中间偏后 |
| 清空、删除历史靠后 | 不可逆，先记路径再动手 |
| H9 最后 | 断网最容易把会话弄坏 |

## 没有截图时最容易翻车的三点

- **路径写得太粗**：`设置 → 模型` 不够，必须到具体控件（`设置 → 模型服务 → 「API Key」输入框`）。
- **只写结论不写现象**：`H2 不通过` 没有证据；要写 `设置 → 模型服务：出现「API Key」「timeout」原文`。
- **事后补记**：路径靠记忆补会漏掉层级；每题测完立刻在第七节记一行，哪怕只写半句。
