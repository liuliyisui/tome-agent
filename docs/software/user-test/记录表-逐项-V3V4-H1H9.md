## 抄进报告时的组装规则

每题只写一句话，结构固定：

```
现象与证据 = 填「否」的那几项连起来，写成"页面 → 控件：现象"
判定依据   = 这张表对应的原则名（V3 用 8pt 网格，V4 用图标一致性，H 系列用 Nielsen 对应条目）
改进建议   = 挑最刺眼的一个「否」，写成"改哪个元素 → 改成什么"
实测结果   = 汇总那一行的结论
```

例：H3 只有 ①③ 有 → `①清空、③重新生成可用；②④⑤⑥ 未找到（S210）` + `部分通过`。

> 填完检查：每个「否」在「现象」里都有对应；每条路径都能照着重走一遍。
