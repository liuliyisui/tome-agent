## 一、四个格子分别写什么

| 栏位 | 写法 | 长度 | 反例 |
|---|---|---|---|
| 实测结果 | 四选一：`通过` / `部分通过` / `不通过` / `未覆盖` | 4 个字 | "基本可以""还行" |
| 现象与证据 | 「在哪一步」+「看到的具体事实」+「操作路径」；事实要带数字、颜色值、原文文案 | 1 句 | "界面有点乱" |
| 判定依据 | 原则名 + 具体条目/阈值 | 1 句 | "感觉不好" |
| 改进建议 | 「改哪个元素 → 改成什么」 | 1 条动作 | "优化体验" |

多小问的题（H1 五态、H3 六项、H5 三场景）在同一格里用 `①②③` 分点，仍保持一行。

## 二、通用判定刻度

- **通过**：该项要求全部满足，最多 1 处不影响使用的瑕疵。
- **部分通过**：多小问缺 1–2 项，或存在 2–4 处不一致。
- **不通过**：核心要求缺失（如五态缺三种、危险操作无确认、错误提示是技术报错）。
- **未覆盖**：产品确实没有该功能或无法触发（如无引用功能 → A2 类题）。能测就必须测。

## 三、逐题：怎么测、记什么、怎么判

| 题 | 怎么测（操作路径） | 判定分界 | 判定依据怎么写 |
|---|---|---|---|
| **V3** | DevTools 取 5 组同类元素：主/次按钮、两张同层卡片、输入框与气泡、两个弹窗、列表项；分别读 `padding`、`gap`、`border-radius`、`box-shadow` | 全部落在同一刻度（≤2 处偏差）→通过；3 种以上不成体系的值→部分；同级元素两种阴影、圆角随手填→不通过 | 8pt 网格 / 设计令牌复用 |
| **V4** | 清点全部图标（发送、重试、清空、设置、箭头、侧栏），记风格/线宽/尺寸/颜色；抽 2 个 SVG 比 `stroke-width`；数插画张数 | 同一套线性图标、线宽尺寸一致、插画 ≤1 →通过；2–4 处不一致（16/20 混用、箭头是填充）→部分；两套图标库或混 emoji→不通过 | 图标一致性（同一视觉重量）；格式塔相似性 |
| **H1** | 依次制造：首次进入（空）→ 发长问题（加载）→ 正常答完（成功）→ 发违规内容（拦截）→ 断网发送（出错）。再录一次"发送→思考→首字→完成"的时间轴 | 五态齐、每阶段有提示、能一眼区分→通过；缺 1–2 态或加载无文案→部分；多态长得一样、无阶段提示→不通过 | Nielsen #1 系统状态可见；状态设计完整性 |
| **H2** | 扫首屏、设置页、加载提示、错误提示，把含技术词的原文抄下来 | 面向用户的提示 0 技术词→通过；只在设置页出现→部分；错误提示直接甩 `API/timeout/500`→不通过 | 使用用户语言（Nielsen #2 系统与真实世界匹配） |
| **H3** | 六项逐个试：清空对话、编辑/撤回上一条、重新生成、中途停止、删除历史、设置恢复默认 | 6/6→通过；4–5 项→部分；≤3 项→不通过 | Nielsen #3 用户控制与自由 |
| **H4** | 同一动作找三处：发送（输入区 / 消息悬停 / 快捷键提示）、清空（设置 / 更多菜单 / 会话列表） | 图标+文案+颜色三处一致→通过；1–2 处不一致→部分；同一动作三种叫法→不通过 | Nielsen #4 一致性；内部一致性 |
| **H5** | ① 空输入点发送 ② 粘贴 1 万字再发送 ③ 点清空对话 | 空输入被禁用/有提示 + 超长有计数或截断提示 + 危险操作二次确认→通过；缺 1 项→部分；空输入直接发出或清空无确认→不通过 | Nielsen #5 错误预防；必填校验与危险操作防护 |
| **H6** | 首次进入只观察不动手：有没有示例问题、预设选项、设置说明 | 三者有其一且可点→通过；只有 placeholder 占位符→部分；光秃秃输入框→不通过 | Nielsen #6 识别优于回忆；降低记忆负担 |
| **H7** | 首次打开就计时：数"打开→第一个答案"的步数与点击次数；试 Enter / Shift+Enter；看设置有无默认值 | ≤2 步且 1 次点击、快捷键可用、有默认值→通过；需先点示例或多一步→部分；要注册/配置才能提问→不通过 | 任务流最短；操作成本 |
| **H8** | 只看主界面，把元素逐个列出来，判断是否服务"提问并拿到答案" | 无无关元素→通过；1–2 处弱相关→部分；首屏被广告/教程横幅/统计卡占据→不通过 | 极简设计；信噪比 |
| **H9** | 断网发送（放最后做）：记录错误原文、输入是否保留、重试是否要重输、有无备选方案 | 说明原因+下一步、保留输入、一键重试→通过；文案笼统但能重试→部分；白屏/技术报错/输入被清空→不通过 | Nielsen #9 帮助用户识别、诊断、恢复 |
