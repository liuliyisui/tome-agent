## 本轮暴露的问题

### 1. 分阶段输出仍重复整章情节

第14章原计划的4个阶段分别为许闻停岗、梁策权限调整、核查组调取证据、两人整理状态。实际4段却都重复了停岗、交钥匙、梁策来电、核查组调取等内容，第16至18章也能看到同场景多版本相继拼接。

第14章各阶段的字数调整记录为：

| 阶段 | 阶段目标 | 初稿 | 保存 |
| --- | ---: | ---: | ---: |
| 1 | 213 | 1195 | 310 |
| 2 | 181 | 812 | 161 |
| 3 | 190 | 1090 | 161 |
| 4 | 219 | 637 | 206 |

写作请求虽有“只展开本阶段”的指令与阶段事件，但仍携带整章小纲；阶段预算只在后续字数调整时使用，调整又缺少阶段上下文。由这些请求和正文可以确认阶段任务边界没有可靠落实；尚未通过对照实验确定各输入因素的独立影响。

### 2. 字数达标后，收束检查继续驱动补章

第15章30019字已经达到原篇幅目标。因未确认收束，程序继续第16至18章，增加6231字，最终超标20.833%。第1至9章已经写出23615字，后续第10至15章只剩较少篇幅，高潮与结尾的分配明显不均。

应分别处理阶段字数预算、全书结尾预留、补章的篇幅政策，不能仅靠增加输出上限解决。

### 3. 收束检查有过度要求，正文也仍有留白

最终模型列出O7、O8、O11三项未完成。其中两项存在明确的判定偏差：

- O7验收条件写的是“职业、法律或人际关系层面的可验证后果”。正文已写停岗、调离项目、改协调岗，模型仍以“法律或人际关系层面的代价未展开”为由不通过，将可选路径变成了额外要求。是否具有充分直接因果仍可讨论，但不能因为没有覆盖全部类别而拒绝。
- O11允许“取得可核验替代证据或原件”。正文已写老钟承认裁切烧毁，时间范围为收页后、拍摄前，并以电子日志备份替代；模型仍以没有精确裁切时刻、没有在原件上恢复为由拒绝，超出了原验收条件。

O8涉及主线定性。第17章交代老钟毁证与复核人手续违规，但第18章仍明确“事故时间两说并列存档，不再推断”，以承认证据边界收尾。它具有结尾形式，却没有按原目标明确解决全部核心矛盾。不能仅凭检查器拒绝就断言全文失败，也不能忽视实际留白和大量重复。

本次人工内容核对重点是第13至18章的结尾与阶段输出，不是整部作品的逐段质量审核。

### 4. 记忆语义整理的原缺口仍存在

三层记忆共646条，全部为 `prose_excerpt`：工作层6条、近期514条、长期126条。321条规划投射记录全部未逐字匹配正文而遗漏；这不等于丢失321条独立事实，正文摘录与来源覆盖完整。

独立的结构化写作状态仍有123条事实、5个对象与176条事件日志，不能说系统没有结构化状态。但是它与正文摘要的衔接没有在本轮修复；工作层仍没有维护一份整合的当前故事状态。
